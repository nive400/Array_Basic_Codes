# Array_Basic_Codes


**Binary Search**

Description: Implements binary search to find an element in a sorted array.

Key Idea: Divide the array into halves until the target is found or search space is empty.

**Bubble Sort**

Description: Sorts an array using the bubble sort algorithm.

Key Idea: Repeatedly swap adjacent elements if they are in the wrong order.

**Even or Odd Number**

Description: Checks whether a given number is even or odd.

Key Idea: Uses modulus operator %.

**Forward and Backward Array**

Description: Prints array elements in forward and backward order.

Key Idea: Traverse array from start to end, then end to start.

**Linear Search**

Description: Implements linear search to find an element in an array.

Key Idea: Sequentially check each element until the target is found.

**Odd and Even Count**

Description: Counts how many odd and even numbers are present in an array.

Key Idea: Iterate through array and increment counters based on % 2.

**Print 1D Array**

Description: Reads input into a 1D array and prints it.

Key Idea: Demonstrates array input/output in Java.

**Sum, Average, Maximum and Minimum**

Description: Calculates sum, average, maximum, and minimum of array elements.

Key Idea: Traverse array once to compute all values.
